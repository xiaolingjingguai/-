# 生态影响评价图件清单与 ArcGIS Pro 制图说明

## 一、依据标准及有效性

（一）《环境影响评价技术导则 生态影响》（HJ 19—2022），生态环境部 2022-01-15 发布、2022-07-01 实施，代替 HJ 19—2011。以用户提供的正式电子版 PDF 核对。截至本次整理，未见该标准修改单（依据为训练资料，建议在生态环境部“环境保护标准”栏目复核）。

（二）本导则附录 D《生态影响评价图件规范与要求》为**规范性附录**（前言），具有强制执行效力；附录 A～C、E 为资料性附录。

（三）附录 D 引用的分类与图式标准（HJ 19—2022 第 2 章引用时均未注日期，按“最新版本适用”执行）：

1. 土地利用分类：GB/T 21010《土地利用现状分类》，据所知现行版为 GB/T 21010—2017；如已发布新版，以新版为准，请复核。
2. 生态系统分类：HJ 1166—2021《全国生态状况调查评估技术规范——生态系统遥感解译与野外核查》。Ⅱ级类型代码及名称请以标准原文为准，本说明不转录（信息不足）。
3. 图式：GB/T 20257《国家基本比例尺地图图式》系列（第 1～4 部分，据所知现行均为 2017 年版，请复核）。

（四）HJ 19—2022 与 2011 版的差别：据所知，2011 版附录 A 按一、二、三级列出“基本图件/推荐图件”对照表；**2022 版已取消该分级对照表**，分级要求分散在 7.4、8.2、9.1 等正文条款中，图件内容要求统一见附录 D 表 D.1。下表“二”中的分级是按正文条款归纳的。

## 三、成图要求（附录 D）

（一）数据时效（D.1）。基础数据应与评价基准时段匹配；7.3.1 规定引用的现状资料调查时间宜在 5 年以内。主题内容无显著变化时可适当放宽，但必须经现场勘验校核。

（二）工作底图与比例尺（D.2）

1. 应采用标准地形图作为工作底图，精度不低于工程设计制图精度，比例尺一般在 1:50000 以上（即分母不大于 50000）。
2. 样方样线布设图、生态监测布点图、生态保护措施平面布置图及设计图一般为 1:10000～1:2000。
3. 底图精度不满足要求时，应开展针对性测绘。
4. 成图范围过大时可点线面结合、分幅成图；涉及生态敏感区时应分幅单独成图。
5. 天地图、商业在线影像不是“标准地形图”，只宜作参考底图；正式工作底图建议向自然资源部门申领 1:10000 或 1:50000 DLG/DOM。

（三）图件内容（表 D.1 要点）

1. 土地利用现状图：采用 GB/T 21010 分类，以**二级类**为基础制图单位。
2. 植被类型图：以植物群落调查成果为基础制图单位（7.3.4 建议以群系及以下为调查单元）；遥感制图应选用与底图精度相适应的分辨率，必要时用高分辨率数据。
3. 植被覆盖度图：基于遥感，用 NDVI 估算，式 C.5：FVC = (NDVI − NDVIs) / (NDVIv − NDVIs)。
4. 生态系统类型图：采用 HJ 1166 分类，以**Ⅱ级**为基础制图单位。
5. 生态敏感区分布图：应在行政主管部门公布的功能分区图上叠加工程要素；不同敏感区重叠时用不同边界线型区分。
6. 样方样线布设图：不同海拔布设的应注明海拔高度。
7. 物种适宜生境分布图：以不同色彩表示不同适宜性等级。

（四）图面辅助要素（D.3）。必须有主图、图名、图例、比例尺、方向标、注记、制图数据源（调查、实验、遥感、预测或其他）、成图时间；图式符合 GB/T 20257。

## 四、ArcGIS Pro 脚本使用方法

（一）运行环境：ArcGIS Pro 3.0 及以上（布局元素创建 API 自 3.0 起提供），Basic 许可即可，不需要 Spatial Analyst。

（二）步骤

1. 把 `eco_maps.py` 复制到本机（如 `D:\生态图件\`），用记事本或 VS Code 修改文件顶部的 `CONFIG`：填写项目占地范围、评价范围（或外扩距离）以及已有专题数据的路径和分类字段；没有的项保持 `None`，对应图件自动跳过，并在日志中提示缺什么。
2. 打开 ArcGIS Pro 工程，在“分析”选项卡中打开 Python 窗口，执行：

   ```python
   exec(open(r"D:\生态图件\eco_maps.py", encoding="utf-8").read())
   ```

3. 输出到 `out_dir`：各图件 PDF 和 JPG（300 dpi）、`*_评价范围面积统计.csv`、`*_工程占用面积统计.csv`、`植被覆盖度分级面积统计.csv`、`制图日志.txt`、`生态制图.gdb`。工程中同时生成同名地图和布局，可继续手工精修。

（三）脚本自动完成的工作

1. 坐标系：按项目中心经度自动选 CGCS2000 3 度带高斯-克吕格。泉州东部多为中央经线 120°E（WKID 4549），安溪、永春、德化等西部多为 117°E（WKID 4548）。也可在 `target_wkid` 中指定。
2. 所有专题数据先投影入库，再裁剪到评价范围，统计各类型面积（hm²）和比例。
3. 图形叠置法（8.2.1 a）d）、附录 C.2）：与项目占地求交，统计工程占用各类型面积及比例。
4. 植被覆盖度：按式 C.5 计算，NDVIs、NDVIv 默认取评价范围内 NDVI 的 5%、95% 分位。导则未规定取值方法，这是行业常用经验做法，报告中须写明。分级断点默认 30%/45%/60%/75%，参照 SL 190—2007 的林草覆盖度分级；导则同样未规定，报告中须写明，可在 CONFIG 中修改。
5. 布局：每幅图自动加图名、指北针、比例尺（图形和数字）、图例、注记（坐标系、制图数据源、制图单位、成图时间），满足 D.3。比例尺自动取能容纳评价范围的标准比例尺（1:2000、1:5000、1:10000、1:25000、1:50000）；超过 1:50000 时在日志中提示分幅。措施平面布置图限制在 1:10000～1:2000。
6. 生态敏感区：`sensitive` 列表中每个敏感区单独成图，按功能分区字段着色并叠加项目占地。

（四）需手工完成或复核

1. 土地利用、生态系统的标准配色：脚本默认随机配色。建议做好一份符合 GB/T 21010 二级类配色的 `.lyrx`，填入 `lyrx` 后自动套用。
2. 公里网/经纬网、图廓整饰、文字位置微调：arcpy 不能直接创建格网，请在布局中“插入 → 格网”。
3. 地理位置图如需省、市两级嵌套小图，请在布局中增加一个地图框。
4. 坐标来自高德或腾讯地图拾取（GCJ-02）时，须先转为 WGS-84/CGCS2000 再入库，可使用“gcj02高德转cgcs2000”工具。

## 五、请提供的项目资料

（一）项目基本信息

1. 项目名称、建设地点（县/区、乡镇）、行业类别、建设内容及规模。
2. 已判定的生态评价等级及依据（HJ 19—2022 6.1）；尚未判定的，提供是否涉及国家公园、自然保护区、自然公园、生态保护红线、重要生境，以及工程占地面积。
3. 评价范围确定依据或外扩距离（6.2）。

（二）空间数据（shp、gdb 或 dwg，需带坐标系）

1. 项目占地范围红线（永久、临时占地分开更好），总平面布置图、施工布置图（dwg）。
2. 工作底图：1:10000 或 1:50000 地形图（DLG/DOM），或至少高分辨率影像。
3. 土地利用：第三次全国国土调查（或最新年度变更调查）图斑，字段含地类编码/名称。
4. 植被：植被调查成果或遥感解译成果；若无，提供样方调查记录（坐标、群落类型）。
5. 遥感影像：Sentinel-2 L2A 或 Landsat 8/9 L2，生长季、云量低，用于植被覆盖度和解译。
6. 生态敏感区：自然保护地边界及功能分区（管理部门公布版）、生态保护红线、公益林、天然林、湿地等矢量数据。
7. 水系、行政区划矢量。
8. 生态保护目标：重要物种分布点、古树名木、重要生境位置。
9. 调查样方、样线、监测点坐标（含海拔）。
10. 生态保护措施布置（表土堆场、绿化、边坡防护、动物通道等）的位置。

（三）制图要求

1. 制图单位名称、图幅（A4/A3）、是否需要单位标准图框。
2. 审批部门对图件的特殊要求（如有）。
