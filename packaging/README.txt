HJ 169 风险计算器（Windows 桌面版）使用说明
依据：《建设项目环境风险评价技术导则》（HJ 169-2018）附录C、D、F、G

一、运行
1. 解压后双击 HJ169_Calculator.exe，免安装，不联网。首次启动需数秒解压。
2. 程序未做数字签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 本软件需授权使用：首次运行若未授权，会弹窗显示本机“机器码”。请复制机器码发给软件作者，
   作者签发授权文件 license.key 后发回给你；把 license.key 放到本程序同一目录，重新启动即可使用。
   授权与本机绑定，不能拷到其它电脑使用。

二、使用流程
1. “物质库”页：按中文名、英文名或 CAS 号搜索（共约 3200 种），右侧显示临界量、终点浓度、理化燃爆毒理参数及来源。
   双击物质或点“设为当前物质并带入参数”，泄漏、蒸发、模型筛选各页的参数自动带入；点“加入 Q 计算”加入风险潜势页。
   也可在窗口顶部“当前物质”框输入名称或 CAS 号，从下拉列表点选，回车或点“带入参数”即带入；已加入 Q 计算的物质以“★Q”标记排在下拉列表最前。
2. “评价等级判定”页：按 Q（附录C.1.1，表B.1/B.2）→ M（表C.1）→ P（表C.2）→ 各要素 E（附录D）→ 各要素风险潜势（表2）→ 评价工作等级（表1）逐步判定，
   Q＜1 直接判为潜势Ⅰ、简单分析；项目综合等级取各要素相对高值（6.4）。同时给出各要素评价范围（4.5：大气一、二级不低于 5 km，三级不低于 3 km，
   管线 200 m／100 m；可填大气毒性终点浓度预测到达距离自动扩大范围；地表水参照 HJ 2.3-2018，地下水参照 HJ 610-2016）和预测评价要求（4.4.4），
   导出的计算书含“环境风险评价工作等级判定表”和结论段落。
   该页右侧上方实时显示判定结果表；点“放大查看／复制”或顶部“评价等级结果”按钮，可打开大字号结果窗口，复制判定表与结论或导出 Word／Excel。
3. “泄漏速率”“液池蒸发”“火灾伴生”“模型筛选”页：按附录F、G 计算，各页结果可联动（如蒸发页自动取泄漏速率）。
4. 每页右侧显示计算过程。“导出 Word”生成 .docx 计算书（宋体／Times New Roman 小四，公文层级标题，参数取值与计算过程为三线表，含公式、代入数值及来源），可直接复制进环评报告；“导出 Excel”生成 .xlsx（汇总表 + 每个模块一张工作表）；“复制文字”复制纯文字。顶部按钮可一次导出全部模块。
   “编制提示（核对后删除）”为程序给出的复核提示，放入报告前请核对后删除。
   sample_report.docx、sample_report.xlsx 为以液氨为例的导出样张。
6. 输错提醒：输入有误时结果区显示红色“✖”错误并停止计算，对应参数名标红；超出常见范围（疑似单位错误）时标橙色“⚠”提醒但仍计算。
   主要拦截：负值或零值；相态与模型不符（如气体温度低于沸点却选“气体泄漏”、常压下储存温度高于沸点却选“液体泄漏”、两相流 F_V≥1 或 ≤0、
   气体泄漏结果接入液池蒸发、液池蒸气压高于环境压力）；压力、温度、密度、摩尔质量、比热容、汽化热等单位明显错误（如 MPa 误填为 Pa、℃ 误填为 K、g/mol 误填为 kg/mol）。
5. 带入的参数旁显示来源；手工修改后显示“用户输入”，请在报告中注明来源。库中缺少的参数显示“信息不足”。

三、适用边界
1. 本程序不做扩散浓度预测。大气风险预测须采用 SLAB、AFTOX 等推荐模型及经认可的软件。
2. 两相流临界压力 P_C 默认按 0.55P（导则原文“取 0.55 Pa”，按量纲推断），可切换。
3. 理化参数请以 MSDS 或手册核对；评价等级结论请工程师复核。

四、自检
selftest_result.txt 为本程序构建后在 Windows 上自动运行的自检记录（计算核心与手算比对、界面与各模块计算）。
